Trading System · 2026

ML-Driven Trading Algorithm

XGBoost GBM Multi-Market Backtesting Signal Generation Portfolio Allocation

Overview

This project develops a machine learning-based trading algorithm that invests across stock markets in multiple countries. Rather than relying on a single market or hand-crafted rules, we use gradient boosting models to learn predictive patterns from cross-sectional and time-series features and translate them into allocation decisions.

The core models are Gradient Boosting Machine (GBM) and XGBoost (XGB), chosen for their strong performance on tabular financial data, interpretability via feature importance, and robustness under noisy market conditions.

Approach

The system is built as an end-to-end pipeline from raw market data to portfolio positions. Features are engineered from price, volume, and derived indicators across markets, then fed into GBM and XGB classifiers or regressors that output trade signals. These signals drive country- and ticker-level allocation within a unified framework.

1. Feature Engineering

  • Price-based features: returns, momentum, volatility, drawdown
  • Volume and liquidity proxies
  • Cross-market and cross-sectional rankings
  • Market-specific normalization to handle heterogeneous exchanges

2. Model Training

  • GBM: sklearn-style gradient boosting as a baseline ensemble model
  • XGBoost: optimized gradient boosting with regularization for generalization
  • Walk-forward and time-series-aware validation to reduce lookahead bias
  • Hyperparameter tuning per market regime where appropriate

3. Signal & Allocation

  • Model outputs converted to long/short or ranked signals per asset
  • Country-level exposure constraints to diversify across regions
  • Position sizing and risk limits applied before execution

Multi-market design. The algorithm is designed to operate across multiple national stock markets, allowing the model to exploit both local patterns and global cross-market relationships rather than overfitting to a single exchange.

Backtesting

Strategies are evaluated through a backtesting framework that accounts for transaction costs, slippage, and realistic rebalancing schedules. Performance is tracked across markets individually and in aggregate to assess whether the GBM/XGB ensemble generalizes beyond any single country.

Status

This project is in active development. Code, documentation, and performance results will be added as the pipeline matures.
